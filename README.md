# 54 m² 一室一厅三维住宅

可旋转、缩放和点选房间的本地 Three.js 页面。模型按视频中的 L 形平面重建，当前版本不连接真实智能设备。

## 打开

在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-3d.ps1
```

也可以从当前目录启动任意静态服务器，例如：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/`。

页面需要 HTTP 服务，不能直接双击 `index.html`，因为浏览器会阻止本地 ES module。

## 手机访问

手机和电脑连接同一个 Wi-Fi 后，使用 `start-3d.ps1` 输出的局域网地址，例如：

```text
http://192.168.31.9:8765/
```

`127.0.0.1` 指的是手机自身，不能在手机上打开电脑的页面。如果手机仍无法访问，需要在 Windows 防火墙提示中允许 Python 通过“专用网络”。

## 交互

- 拖动旋转，滚轮或双指缩放。
- 点击墙体、地面或家具选择房间。
- 全屋、卧室、客餐厅、厨房、浴室和阳台有独立相机视角。
- `剖切墙体` 在低墙和完整墙体之间切换。
- `房间标注` 控制三维文字。
- `自动旋转` 可随时暂停；开启时保持可见的暂停按钮。

## 结构基准

- 总建筑面积：约 54 m²。
- 主体：约 11.4 × 3.8 m。
- 下部厨房与门厅：额外约 1.55 m 进深。
- 主要家具采用标准模数，绝对尺寸误差约 ±0.15 m。
